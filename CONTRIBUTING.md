# Reproducing and contributing

1. Use the same input CSV schema described in `data/README.md`.
2. Run the notebook top to bottom in Google Colab.
3. Avoid committing private datasets or local credentials.
4. If changing code, describe any changes to data-cleaning assumptions and whether the reported outputs still match.
5. Do not interpret category counts as population-normalised rates or use `id` as a substantive clustering feature.
